  🚀 QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════════════

  1. INSTALL DEPENDENCIES
     $ pip install -r requirements.txt
     $ pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

  2. PREPARE DATA
     # Option A: Use your own data
     $ cp /path/to/your/data.csv data/data_export.csv

     # Option B: Generate sample data
     $ python utils/generate_sample_data.py --candles 10000

  3. TRAIN MODEL
     # Full pipeline (all 3 phases)
     $ python train_natron.py --data data/data_export.csv

     # Quick training (supervised only)
     $ python train_natron.py --data data/data_export.csv --skip-pretrain --skip-rl

  4. START INFERENCE SERVER
     # Socket server (for MetaTrader 5)
     $ python src/inference/socket_server.py

     # Or Flask API (for HTTP requests)
     $ python src/inference/flask_api.py

  5. CONNECT METATRADER 5
     - Copy mql5/natron_ea.mq5 to MT5/MQL5/Experts/
     - Compile in MetaEditor (F7)
     - Attach to chart and configure
     - Enable AutoTrading

  6. MONITOR SYSTEM
     $ python deployment/monitor_natron.py
     $ tensorboard --logdir logs

  Output:

    - Confidence Score: [0, 1]

  Training:
    - Phase 1: 50 epochs (pretraining)
    - Phase 2: 100 epochs (supervised)
    - Phase 3: 50 episodes (RL)
    - Optimizer: AdamW (lr=0.0001)
    - Batch Size: 32

  0: BULL_STRONG   - Strong uptrend (trend > +2%, ADX > 25)
  1: BULL_WEAK     - Weak uptrend (0 < trend ≤ 2%, ADX ≤ 25)
  2: RANGE         - Sideways/lateral market
  3: BEAR_WEAK     - Weak downtrend (-2% ≤ trend < 0, ADX ≤ 25)
  4: BEAR_STRONG   - Strong downtrend (trend < -2%, ADX > 25)
  5: VOLATILE      - High volatility (ATR > 90th percentile)
