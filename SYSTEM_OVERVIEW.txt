🚀 QUICK START (5 COMMANDS)

1. Setup Environment:
   python3.10 -m venv venv && source venv/bin/activate
   pip install -r requirements.txt

2. Prepare Data:
   cp /your/data/path.csv data/data_export.csv

3. Train Models (~9 hours on GPU):
   python scripts/train_full_pipeline.py

4. Start Server:
   ./scripts/start_server.sh

5. Deploy MetaTrader EA:
   Copy mql5/natron_ea.mq5 to MT5 Experts folder
   Compile and attach to chart

📊 MODEL SPECIFICATIONS

Architecture:
  • Input: 96 consecutive OHLCV candles
  • Features: 100 technical indicators
  • Encoder: 6-layer Transformer (256d, 8 heads, 1024 FFN)
  • Heads: Buy (sigmoid), Sell (sigmoid), Direction (2-class), Regime (6-class)
  • Parameters: ~5 million trainable

Training:
  • Phase 1: Unsupervised (masked + contrastive) - 50 epochs (~3h)
  • Phase 2: Supervised (multi-task) - 100 epochs (~4h)
  • Phase 3: RL (PPO) - 1000 episodes (~2h)
  • Total: ~9 hours on NVIDIA RTX 3080

Performance:
  • Buy/Sell Accuracy: 60-70%
  • Direction Accuracy: 55-65%
  • Regime Accuracy: 70-80%
  • Inference Latency: <50ms

🔧 API ENDPOINTS

REST API (Flask):
  GET  /health              - Health check
  POST /predict             - JSON prediction
  POST /predict_csv         - CSV file prediction

Socket API (TCP):
  Port: 9090                - MQL5 bidirectional communication

Example Request:
{
  "data": [
    {"time": "2023-01-01 00:00", "open": 1.05, "high": 1.052, 
     "low": 1.049, "close": 1.051, "volume": 15000},
    ... (96 candles total)
  ]
}

Example Response:
{
  "buy_prob": 0.71,
  "sell_prob": 0.24,
  "direction_up": 0.69,
  "regime": "BULL_WEAK",
  "confidence": 0.82,
  "signal": "BUY"
}

🐳 DOCKER DEPLOYMENT

Build:
  docker build -t natron-transformer .

Run:
  docker run -d \
    --name natron \
    --gpus all \
    -p 5000:5000 \
    -p 9090:9090 \
    -v $(pwd)/model:/app/model \
    -v $(pwd)/data:/app/data \
    natron-transformer

Health Check:
  curl http://localhost:5000/health
